# Pollos King — Menú web

Proyecto estático hecho con HTML, CSS y JavaScript.

## Archivos
- `index.html`: menú público.
- `admin.html`: panel de administración.
- `css/styles.css`: diseño del menú.
- `css/admin.css`: estilos adicionales del administrador.
- `js/menu.js`: carga y muestra productos/configuración.
- `js/admin.js`: CRUD de productos y configuración.
- `assets/pollos-king-bg.svg`: fondo local inicial.

## Cómo usar
1. Abre `index.html` para ver el menú.
2. Abre `admin.html` para administrar.
3. Los cambios se guardan en `localStorage` del navegador.
4. Las imágenes seleccionadas se guardan como datos locales dentro del navegador.

## Importante
Este administrador es para una página estática/local. No tiene base de datos ni autenticación real. Para publicar un administrador multiusuario con seguridad, habría que conectarlo a un backend y una base de datos.
